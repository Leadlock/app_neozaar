Enterprise Ready for Tech Startups — Deployment Package

1. Extract this ZIP.
2. Upload index.html to your web hosting document root (for example public_html).
3. Open your domain to view the page. No npm installation or build is required.

The HTML contains the page styling and JavaScript. Google Fonts are loaded online; fallback fonts are available.

Before launch: the booking button currently uses mailto: without a recipient. Set a recipient email or replace it with your scheduling URL in index.html.
